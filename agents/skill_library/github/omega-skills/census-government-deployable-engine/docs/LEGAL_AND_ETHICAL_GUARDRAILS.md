# Legal and Ethical Guardrails

## Hard boundary

CENSUS is a civic-witness and transparency engine. It is not a secret surveillance platform, not an enforcement targeter, and not a system for unreviewable automated decisions.

## Required controls before government use

1. Legal basis for every data source.
2. Data minimization.
3. Purpose limitation.
4. Consent where required.
5. Independent oversight.
6. Human review for any consequential use.
7. Citizen access and correction rights.
8. Appeal path.
9. Audit logs.
10. Sunset/review period.
11. Privacy impact assessment.
12. Security review.

## Prohibited deployments

- Secret citizen scoring.
- Predictive policing or enforcement targeting without lawful independent process.
- Denial of services, rights, benefits, housing, employment, education, credit, or healthcare based only on engine output.
- Unreviewable watchlists.
- Raw private-data sharing.
- Deployment without correction/appeal.

## Safe deployments

- Service-delivery backlog mapping.
- Record reconciliation.
- Public-interest anomaly detection with oversight.
- Citizen-facing self-knowledge reports.
- Historical evidence organization.
- Audit and transparency dashboards.
