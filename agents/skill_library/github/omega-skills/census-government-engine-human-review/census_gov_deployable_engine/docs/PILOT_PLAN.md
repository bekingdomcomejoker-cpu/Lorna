# Pilot Plan

## Phase 0 — Desk review

- Review code, docs, and redacted data.
- Confirm legal basis and data protection requirements.
- Confirm prohibited use cases.
- Appoint oversight reviewer.

## Phase 1 — Synthetic or voluntary pilot

- Use synthetic records or voluntary participant data.
- Run ingestion/promotional pipeline in a closed environment.
- Produce reports for participants and oversight team.
- Test correction and appeal process.

## Phase 2 — Service-delivery pilot

- Use approved non-sensitive administrative/service-delivery records.
- Aggregate results by location/service category.
- Avoid individual adverse decisions.
- Measure whether CENSUS improves record reconciliation and response planning.

## Phase 3 — Independent evaluation

- Accuracy review.
- Bias/impact review.
- Privacy/security review.
- Citizen feedback.
- Sunset/review decision.
